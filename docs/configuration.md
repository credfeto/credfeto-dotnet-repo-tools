# Configuration File Reference

## repos.lst

One line per repository to process, e.g.:

```text
git@github.com:credfeto/repo1.git
git@github.com:credfeto/repo2.git
git@github.com:credfeto/repo3.git
```

## tracking.json

Generated by the tool; do not hand-edit.

## cache.json

Generated by the tool; do not hand-edit.

## packages.json

A JSON array of package update rules. Each entry describes one package (or package prefix) to keep updated, and optionally packages to exclude from that rule.

```json
[
  {
    "packageId": "Credfeto.",
    "type": "PRODUCTION",
    "exact-match": false,
    "version-bump-package": true,
    "prohibit-version-bump-when-referenced": false,
    "exclude": [
      {
        "packageId": "Credfeto.Legacy.Package",
        "exact-match": true
      }
    ]
  },
  {
    "packageId": "xunit",
    "type": "TESTING",
    "exact-match": true,
    "version-bump-package": true,
    "prohibit-version-bump-when-referenced": false,
    "exclude": []
  }
]
```

| Field | Description |
| --- | --- |
| `packageId` | Package id, or package id prefix when `exact-match` is `false` |
| `type` | Free-text category for the package (e.g. `PRODUCTION`, `TESTING`) |
| `exact-match` | `true` to match `packageId` exactly; `false` to match it as a prefix |
| `version-bump-package` | Whether matching packages should be version-bumped |
| `prohibit-version-bump-when-referenced` | Whether a version bump is blocked while this package is referenced |
| `exclude` | Optional list of packages to exclude from this rule, each with its own `packageId` / `exact-match` |

## release.json

Defines the configuration for generating releases when multiple packages have been updated.

```json
{
  "settings": {
    "autoReleasePendingPackages": 1,
    "minimumHoursBeforeAutoRelease": 5,
    "inactivityHoursBeforeAutoRelease": 9
  },
  "neverRelease": [
    {
      "repo": "credfeto/cs-template",
      "match": "exact",
      "include": true
    }
  ],
  "allowedAutoUpgrade": [
    {
      "repo": "credfeto/",
      "match": "contains",
      "include": true
    }
  ],
  "alwaysMatch": []
}
```

| Field | Description |
| --- | --- |
| `settings.autoReleasePendingPackages` | Number of pending package updates before an automatic release is created |
| `settings.minimumHoursBeforeAutoRelease` | Minimum hours to wait after the last change before auto-releasing |
| `settings.inactivityHoursBeforeAutoRelease` | Hours of inactivity before auto-releasing regardless of the minimum wait |
| `neverRelease` | Repositories that should never be auto-released |
| `allowedAutoUpgrade` | Repositories allowed to be auto-upgraded |
| `alwaysMatch` | Repositories always treated as matching, regardless of the rules above |

Each entry in `neverRelease` / `allowedAutoUpgrade` / `alwaysMatch` has:

| Field | Description |
| --- | --- |
| `repo` | Repository name or name fragment to match |
| `match` | `exact` or `contains` |
| `include` | Whether a match includes (`true`) or excludes (`false`) the repository |

## template.json

Used by `update-template` (`--template-config`) to describe which files, folders, and settings should be synced from the template repository into each managed repository.

```json
{
  "general": {
    "files": {
      ".editorconfig": "Config",
      ".gitignore": "Config"
    },
    "mirror-folders": {},
    "partial-files": {}
  },
  "dotNet": {
    "global-json": true,
    "resharper-dotsettings": true,
    "files": {}
  },
  "gitHub": {
    "issue-templates": true,
    "pr-template": true,
    "actions": true,
    "linters": true,
    "files": {},
    "dependabot": {
      "generate": true
    },
    "labels": {
      "generate": true
    }
  },
  "cleanup": {
    "files": {}
  }
}
```

| Section | Description |
| --- | --- |
| `general.files` | Map of source path to category for general files to sync |
| `general.mirror-folders` | Folders mirrored wholesale from the template |
| `general.partial-files` | Files synced only in part, keyed by path, each with a `type` and optional `match` |
| `dotNet.global-json` | Whether to sync `global.json` |
| `dotNet.resharper-dotsettings` | Whether to sync the ReSharper `.dotsettings` file |
| `dotNet.files` | Additional .NET-specific files to sync |
| `gitHub.issue-templates` | Whether to sync GitHub issue templates |
| `gitHub.pr-template` | Whether to sync the pull request template |
| `gitHub.actions` | Whether to sync GitHub Actions workflows |
| `gitHub.linters` | Whether to sync linter configuration |
| `gitHub.files` | Additional GitHub-specific files to sync |
| `gitHub.dependabot.generate` | Whether to (re)generate Dependabot configuration |
| `gitHub.labels.generate` | Whether to (re)generate `labels.yml` / `labeler.yml`; see [GitHub Labels Reference](github-labels.md) |
| `cleanup.files` | Files to remove/clean up in the managed repository |
